## Unofficial project

**Unofficial fan-made technical showcase. Not affiliated with, endorsed by, or presented as an official Blablaland project.**

The characters' lines are written by an AI model (Claude, by Anthropic) from personalities, rules and situations defined by the project. This project is not affiliated with, endorsed by, or sponsored by Anthropic; Claude is a trademark of Anthropic.

The dialogue excerpts quoted in this repository come from test sessions played with test accounts. No real player's name, message or data appears in this repository.
